# 確認用アクセスをGA4へ送らない運用

2026-10-21：杉本さんの「私やあなたが確認のために公式サイトを見たアクセスが、お客様のアクセスに混ざらないように」の依頼に対応。

1. サイトを確認するブラウザで https://buttokuikiro.com/staff-check/ を開く。このページ自体にはGA4を読み込まない。
2. 「このブラウザを集計から除外する」を押し、設定済みの表示を確認する。
3. ページ内のリンクで公式サイトを開き、「確認用アクセス：集計対象外」の表示を確認してから閲覧・操作する。既に開いていたサイトのタブは再読み込みする。
4. 別端末・ブラウザ・プロファイル、プライベート閲覧、データ削除後、エージェントの新しいブラウザ環境でも毎回1〜3を確認する。表示がなければ除外済みと扱わず、先に設定する。

ブラウザ内にこのサイト専用の除外設定を保存する。IPアドレスでの一括除外はしない。除外済みのページはGoogleタグ自体を読み込まず、`ga-disable-G-BLYH7L3V1X` も有効にする。既存のカスタムイベントは何も送らない。設定されていない通常ブラウザでは従来のID・イベントを維持する。

対象はこのドメインのGA4のみ。Google検索/Search Console・Googleマップ/GBP・外部サイト・過去の記録には適用されない。除外済みブラウザでの操作がGA4リアルタイムに出ないことは仕様であり、計測故障と判断しない。実際の送信確認が必要な場合は、通常モードを使うテストの日時と内容を別途記録する。

全公開ページと生成元 `tools/analytics.py` に反映する。多言語・お知らせの再生成でも除外を維持する。`node tools/check_analytics.mjs` で通常計測、除外、他タブ、戻る操作、保存領域の利用不可を検証する。設定ページはサイトマップやお客様向けナビゲーションに追加しない。
